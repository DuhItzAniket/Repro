# Phase records

One file per phase, `<ID>-<slug>.md`, created from
[`../process/PHASE_TEMPLATE.md`](../process/PHASE_TEMPLATE.md) when the phase starts and
completed when it merges. Stage gates are recorded as `<STAGE>-gate.md`.

The status of every phase lives in [`../ROADMAP.md`](../ROADMAP.md). This folder holds the
detail: what was built, the evidence that it works, deviations from the spec, and known gaps.
