## How to read the tags

| Tag | Meaning |
|---|---|
| **[V]** | Verified: the primary source was fetched and the claim seen there |
| **[V-local]** | Checked by running a command or small experiment on a development machine |
| **[S]** | Seen only in a search snippet or a secondary source (named) |
| **[U]** | Unverified, from general knowledge, or the author's inference |
| **[A]** / **[calc]** | The author's own analysis or arithmetic; not a sourced fact |

## Provenance and caveats

- These notes were produced with AI-assisted web research and reviewed by the maintainers.
  Claims the plan depends on were spot-checked against primary sources.
- The research tools' search budget ran out partway through. Later facts were checked by
  direct fetches of known URLs only. **Literature discovery for 2025–2026 is incomplete.**
- Product features, prices and versions change quickly. Treat anything here as a snapshot of
  2026-10-13.
- Several fetched pages contained text addressed to AI agents (for example, "instructions" to
  call a particular tool). That text was treated as data and ignored. The notes mention where
  this happened.
- Before citing anything in a paper, re-read the primary source. Entries summarised from
  background knowledge are marked **(k)** in `02-literature.md`.
